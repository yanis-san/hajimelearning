## 🔴 Critique — Manquant

### 1. Certificat de complétion (PDF)
Générer un PDF personnalisé (nom étudiant, cours, date) quand 100% des leçons sont terminées.
Signe distinctif d'un LMS pro. Les étudiants l'attendent.

**Stack suggérée** : `WeasyPrint` ou `ReportLab` + template HTML → PDF via Celery (async)

---

### 2. Logique de complétion cours
`StudentProgress` trace les leçons terminées mais il n'y a pas de signal ni de méthode qui :
- calcule si toutes les leçons publiées d'un cours sont terminées
- déclenche le certificat + une notification "Félicitations"
- enregistre la date de complétion

**Modèle manquant** :
```python
class CourseCompletion(models.Model):
    student    = ForeignKey(User)
    course     = ForeignKey(Course)
    completed_at = DateTimeField(auto_now_add=True)
    certificate_url = CharField(blank=True)  # lien S3 du PDF
```

---

### 3. PostgreSQL en production
`base.py` utilise SQLite. SQLite = zéro concurrence, pas utilisable en prod.

```python
# À ajouter dans base.py
import dj_database_url
DATABASES = {
    'default': dj_database_url.config(
        default=env('DATABASE_URL'),
        conn_max_age=600,
        conn_health_checks=True,
    )
}
```

---

### 4. Stockage médias (S3 / Cloudflare R2)
Les uploads (thumbnails, preuves de paiement, fichiers cours) sont stockés sur disque local.
En prod multi-instance ou serverless, les fichiers sont perdus au redémarrage.

```python
# prod.py
DEFAULT_FILE_STORAGE = 'storages.backends.s3boto3.S3Boto3Storage'
AWS_STORAGE_BUCKET_NAME = env('R2_BUCKET_NAME')
AWS_S3_ENDPOINT_URL     = env('R2_ENDPOINT_URL')
```

Créer `templates/404.html` et `templates/500.html` avec le design du site.

## 🟠 Important — Manquant

### 6. Avis & Notes (étoiles)
Les étudiants ne peuvent pas noter ni commenter un cours.
Or les avis ★★★★☆ = preuve sociale = taux de conversion.

**Modèle à créer** :
```python
class Review(models.Model):
    student  = ForeignKey(User)
    course   = ForeignKey(Course)
    rating   = IntegerField(validators=[MinValueValidator(1), MaxValueValidator(5)])
    comment  = TextField(blank=True)
    created_at = DateTimeField(auto_now_add=True)

    class Meta:
        unique_together = ['student', 'course']
```

Afficher la note moyenne sur les cartes et la landing page.

---

### 7. "Continuer où j'en étais"
Le dashboard ne propose pas de bouton direct vers la dernière leçon non terminée.
C'est la fonctionnalité UX n°1 d'un LMS (Udemy, OpenClassrooms…).

**Logique** :
```python
last_lesson = (
    Lesson.objects
    .filter(module__course=course, is_published=True)
    .exclude(progress__student=student)
    .order_by('module__order', 'order')
    .first()
)
```

### 9. Annonces cours (Announcements)
L'instructeur ne peut pas envoyer une newsletter à tous ses inscrits (ex: "nouvelle leçon ajoutée", "promo").
Fonctionnalité présente sur Udemy, Teachable, Podia.

**Modèle à créer** :
```python
class Announcement(models.Model):
    course   = ForeignKey(Course)
    title    = CharField(max_length=200)
    body     = TextField()
    sent_at  = DateTimeField(auto_now_add=True)
```
Signal → Celery → email à tous les `AccessRequest(status='APPROVED')` du cours.

## 🟡 Utile — Manquant

### 11. Dashboard analytics admin
Aucune vue synthétique : CA mensuel, nombre d'inscrits, cours les plus populaires, taux de complétion.
Nécessaire pour piloter le business.

---

### 12. Rate limiting sur l'auth
Les endpoints de login, signup, reset password ne sont pas throttlés.
Un attaquant peut faire du brute-force ou du spam d'emails.

```python
# Avec django-axes ou django-ratelimit
pip install django-axes
INSTALLED_APPS += ['axes']
AXES_FAILURE_LIMIT = 5
AXES_COOLOFF_TIME = 1  # heure
```

---

### 13. Favoris / Liste d'envies
Pas de moyen de sauvegarder un cours pour plus tard.
Conversion différée : l'étudiant revient acheter quand il est prêt.

---

### 14. Nombre d'inscrits visible
Les cartes et landing pages n'affichent pas "X étudiants inscrits".
Preuve sociale légère mais efficace.

```python
# Propriété sur Course
@property
def students_count(self):
    return AccessRequest.objects.filter(course=self, status='APPROVED').count()
```

### 15. Notes personnelles par leçon
L'étudiant ne peut pas prendre de notes associées à une leçon.
Différenciateur fort vs YouTube — l'étudiant reste sur la plateforme.
